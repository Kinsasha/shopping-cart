# Project Name

Shopping Cart App

The Shopping cart app is a light online shopping app focused on the frontend. It retrieves data from the fakestore api and renders it in the shopping page of the 3-page app. The other pages are the home/landing page and the cart/checkout page. It uses react router for routes.

## Features

- Home page for introduction
- addition of desired products and qunatities to cart
- deadend checkout section where the grand total is calculated

## Built With

- React
- HTML & CSS
- REST Api

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   bash
   git clone git@github.com:Kinsasha/shopping-cart.git

2. Navigate into the project directory:

   bash
   cd shopping-cart

3. Install dependencies:

   bash
   npm install

4. Open localhost:

   bash
   npm run dev

5. Open `http://localhost:5173` in your browser.
